# T1 - Slot distribution

## What to do

Add `modeling::docking` with `slot`, `distribute`, `apply` and `distribute_all`; run `apply` once per
top-level `Command::execute` (compound sub-commands use a private `apply`), and `distribute_all`
after `orthogonalize_all` in `canvas::persist::open`.

## Context

Layout docks every end at its side middle (`layout::preferred_keeping`); slots post-process those
ends instead of changing the layout tables.

## Implementation

Group ends by (shape, `border_side`), sort by rounded position along the side then by the other end,
move each to `(i + 0.5) / n`, re-orthogonalize. Undo is a trailing step of the command undo.
