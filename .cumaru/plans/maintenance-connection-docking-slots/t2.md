# T2 - Redock gesture

## What to do

`docking::redock(defs, id, start, at)` returns an `UpdateWaypoints` that moves the end to the border
point nearest `at`; the endpoint drag in `canvas/view.rs` uses it when the drop shape is the end's own.

## Context

`factory::reconnect` produced no change for the same shape, so this drop was a no-op before.

## Implementation

Same side: replace the end point. Other side: `layout::side_route` (join, else detour) from the new
side to the far end. The slot pass then orders the end by its dropped position.

## Done when

- [x] `redock_reorders_slots_on_the_same_side`, `redock_moves_an_end_to_another_side` pass.
- [x] `parity::drag_end_along_own_shape_redocks` fails without the canvas branch and passes with it.
