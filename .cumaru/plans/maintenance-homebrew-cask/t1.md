# T1 — publish SHA256SUMS with every GitHub release

## What to do

In the `release` job of `.github/workflows/ci.yml`, after downloading the artifacts, write `dist/SHA256SUMS` (`sha256sum` over the DMG, zip and tarball) and attach it with the other files.

## Context

- Release job uses `actions/download-artifact@v4` (merge-multiple into `dist`) and `softprops/action-gh-release@v2`.
- Verify locally by running the same `sha256sum` command over the current v0.1.0 assets downloaded with `gh release download v0.1.0` into the scratchpad.
