# T1 — Pure per-kind option catalog

## What to do

Add `src/canvas/inspector.rs` with a GPUI-free function, e.g.
`options(defs: &Definitions, selection: &[ElementId]) -> Panel`, returning the
header (kind, id) and an ordered list of `InspectorOption`s for the selection,
exactly as the catalog table in the plan `index.md` defines.

Option shapes: `Info(label, value)`, `Text { field, value, multiline }`,
`Toggle { field, value }`, `Select { field, value, choices }`, `Action(action)`.
`field` is an enum naming the attribute (`Name`, `Documentation`,
`IsExecutable`, `IsInterrupting`, `CancelActivity`, `Timer`, `Condition`,
`IsDefault`, `DefaultFlow`, `IsForCompensation`, `AssociationDirection`, ...).

## Context

- Pattern: `context_pad::entries(kind, replaceable)` (`src/canvas/context_pad.rs:70`).
- Reuse, do not re-encode: replace options (`factory::replace_options`), lane tools (`context_pad::entries`), collapse (`view_planes::collapse_state`, `src/canvas/view_planes.rs:57`; extract its predicate if GPUI-bound).
- Model: `ElementKind` (`src/model/kind.rs`), `ElementDetails` (`src/model/details.rs`).
