# T2 — `UpdateProperties` command with exact undo

## What to do

Add `Command::UpdateProperties { id, change: PropertyChange }` where
`PropertyChange` names one attribute and its new value: `Documentation`,
`IsExecutable`, `IsInterrupting`, `CancelActivity`, `Timer`, `EventCondition`,
`FlowCondition`, `IsDefault`, `IsForCompensation`, `AssociationDirection`.

Making a sequence flow default clears `is_default` on every other outgoing
sequence flow of the same source inside the same command (bpmn-js
`UpdatePropertiesHandler` does the same for `default`).

## Context

- Undo: `Command::UpdateLabel` snapshots with `undo.element(defs, id)` before mutating (`src/modeling/command.rs:186`); snapshot every touched flow for the default case.
- Model: `ElementDetails` (`src/model/details.rs`), `SequenceFlow { is_default, condition }` (`src/model/kind.rs`).
- Export already writes these attributes (`src/io/export.rs`: `isExecutable`, `associationDirection`, `conditionExpression`, timers, documentation).
- Reference: https://github.com/bpmn-io/bpmn-js/blob/v17.11.1/lib/features/modeling/cmd/UpdatePropertiesHandler.js

## Implementation

1. Red: per-variant apply/undo tests; default exclusivity test; refusal on unknown id or a change that does not fit the kind (returns `None`).
2. Red: export -> import round-trip per variant.
3. Green: implement the variant.
