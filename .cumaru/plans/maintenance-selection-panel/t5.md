# T5 — Text options with focus isolation

## What to do

Make the panel's `Text` options editable with `TextInput`: name -> `UpdateLabel`;
documentation, flow condition, event condition, timer expression ->
`UpdateProperties`. Enter or blur commits when changed (shift+Enter newline in
multi-line fields), Escape restores. Canvas keys must not reach the selection
while a field has focus.

## Context

- Inline label editor: `Canvas::editing`, `TextInput` (`src/canvas/text_input.rs`), commit path in `view_overlays.rs`.
- Canvas keys are bound on `surface` via `key_context("Canvas")` and `on_key_down`; the panel lives outside `surface`, so its own focus handle should stop dispatch — prove it.
- Field entities must be reset when the selection, tab, plane or document changes.

## Implementation

1. Red: tests — rename via panel then undo; Backspace in a field does not delete the element; Escape restores; selection change discards an uncommitted edit; condition edit round-trips through export.
2. Green: field entities on `Canvas`, sync on selection change, commit/cancel handlers.
