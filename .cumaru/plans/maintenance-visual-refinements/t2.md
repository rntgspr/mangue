# T2 — Integrate the macOS title area

## What to do

Replace the separate macOS title bar with an integrated title area containing the document tabs, inspired by Zed, and investigate the reported clipped top line.

## Context

The current window uses default system title bar options. GPUI supports a transparent title bar and native traffic lights; their positioning and dragging need verification in a real window. Other platforms retain their existing window and menu behavior.

## Implementation

Inspect the window and tab layout, reproduce the clipping, then implement the smallest correct integration. Account for empty windows, sidebar visibility, narrow widths and full-screen mode.

## Done when

- [ ] Tabs and their top edge are visible without a separate macOS title bar.
- [ ] Native window controls and dragging work with and without an open document.
- [ ] Tab navigation and non-macOS window behavior remain intact.
- [ ] Relevant automated checks and a real macOS visual and interaction smoke test are recorded.
