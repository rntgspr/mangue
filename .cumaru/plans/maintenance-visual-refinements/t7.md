# T7 — Show selection in the document breadcrumb

## What to do

## Context

Selection is owned by the active document and uses the model's XML element IDs. The canvas already has a separate breadcrumb for navigating subprocess planes.

## Implementation

Derive header content from the active document's selection and update it as selection or tabs change.
