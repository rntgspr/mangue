# T9 — Reveal selected element in XML

## What to do

When entering code mode with one selected diagram element, find its semantic XML element by ID, scroll it into view and highlight it without selecting text.

## Context

The editor displays exported XML and supports independent range decorations and cursor-based reveal. Multiple or missing selections do not identify a single target.

## Implementation

Use XML parsing to locate the exact ID attribute and the editor's decoration API. The visual marker follows the preview selection independently of the editor's text selection. Preserve editing and code sync.

## Done when

- [ ] The matching element is revealed and visibly highlighted without a text selection.
- [ ] Missing, multiple and unmatched selections leave normal code-mode behavior intact.
