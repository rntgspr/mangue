# Changelog

All notable changes to this project are documented in this file. The format is

## [Unreleased]

### Added

## [0.1.0]

### Added

- Native BPMN 2.0 modeler for macOS, Windows and Linux: open, edit and save
  diagrams on a pan/zoom canvas, tabs, BPMN XML code mode and YAML themes.
- Packages: universal macOS DMG, Windows zip and Linux tarball.
