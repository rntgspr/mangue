# Security Policy

## Supported versions

Only the latest published release receives security fixes.

## Reporting a vulnerability

Please do not open a public issue. Report privately through
[GitHub private vulnerability reporting](https://github.com/rntgspr/mangue/security/advisories/new),
or email **rntgspr@gmail.com** with "Mangue security" in the subject.

Include the affected version and platform, the impact, and steps or a `.bpmn`
file that reproduces the problem. You will get an acknowledgement within 7 days;
a fix and advisory are coordinated with you before public disclosure.
