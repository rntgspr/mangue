# Mangue app icon

Generated with the built-in image generation tool. `mangue.png` is the original
1254 x 1254 image with alpha transparency. `Mangue.icns` contains macOS icon
representations from 16 x 16 through 1024 x 1024, packaged with `sips` and
`iconutil`. The asset is not yet wired into the app bundle.

The visual concept draws on the native BPMN modeler described in
[the modeler spec](../../.cumaru/specs/modeler/index.md) and the Solarized colors
in [the theme spec](../../.cumaru/specs/modeler/theme.md). The mangrove-root
metaphor is an artistic interpretation of the project name.

## Generation prompt

```text
Use case: logo-brand
Asset type: finished macOS application icon for Mangue, a native Rust desktop BPMN 2.0 visual process modeler.
Primary request: Design one polished, distinctive app icon combining mangrove roots with a compact process-flow symbol. It must read as an intentional app identity at small Dock sizes.
Scene/backdrop: one deep petrol-blue rounded-square tile, gently convex ceramic/enamel surface, restrained bevel, subtly lighter upper edge, transparent outside the tile. Square 1024 by 1024 image with the tile centered and occupying about 84 percent of width and height.
Subject: one bold continuous ivory and seafoam geometric emblem. A small upper rounded rectangular process node connects through a short central stem to a central diamond gateway, branching into three strong elegant root-like paths ending in compact rounded rectangular nodes below. The overall root silhouette gently suggests an M. Use spacious negative space, very few parts, substantial stroke thickness. Connectors turn through crisp orthogonal routes with softly rounded elbows. Abstract mangrove roots, not a literal tree illustration.
Style/medium: beautifully crafted macOS app icon, shallow three-dimensional enamel relief, precise graphic geometry, sophisticated minimalism, strong silhouette, quiet tactile finish.
Lighting/mood: soft upper-left studio light, controlled highlights, gentle contact shadows within the tile.
Color palette: drawn from the project's Solarized theme: deep petrol #002b36 and #073642 for tile, warm ivory #fdf6e3 and teal #2aa198 for emblem, subtle seafoam highlights.
Composition/framing: straight-on centered orthographic view, balanced emblem centered on tile, no perspective tilt. Large simple emblem; generous breathing room around it.
Text: none.
Constraints: a single finished icon only, alpha transparency outside tile, no mockup scene, no labels, no type, no letters, no watermark, no grid, no tiny detail, no extra disconnected decorations, no neon glow, no purple, no photorealistic vegetation.
```
